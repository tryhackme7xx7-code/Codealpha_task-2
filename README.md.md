# CodeAlpha Phishing Awareness Training



## &#x20;CodeAlpha Cyber Security Internship — Task 2



### &#x20;Project Description



This project is a Phishing Awareness Training presentation created as part of the CodeAlpha Cyber Security Internship.



The presentation is designed to help employees and students understand phishing attacks, recognize suspicious messages and websites, understand social engineering techniques, and follow safe cybersecurity practices.



#### &#x20;Objectives



The main objectives of this project are:



\* Explain what phishing is.

\* Explain how a phishing attack works.

\* Identify common phishing email warning signs.

\* Identify warning signs of fake websites.

\* Explain social engineering tactics.

\* Present real-world phishing and social-engineering examples.

\* Provide practical security best practices.

\* Test awareness through an interactive phishing quiz.



\### Topics Covered



The presentation covers:



1\. What is Phishing?

2\. How a Phishing Attack Works

3\. Recognizing Phishing Emails

4\. Recognizing Fake Websites

5\. Social Engineering Tactics

6\. Real-World Examples

7\. Best Practices to Stay Protected

8\. Phishing Awareness Quiz

9\. Answers and Key Takeaways



\### Presentation



\*\*File:\*\* `Phishing\_Awareness\_Training.pptx`



The presentation contains 12 slides covering phishing awareness, detection techniques, social engineering, real-world examples, security recommendations, and a knowledge-check quiz.



\### Key Phishing Warning Signs



The presentation explains several warning signs, including:



\* Mismatched sender addresses

\* Urgent or threatening messages

\* Suspicious links

\* Unexpected attachments

\* Spelling and grammar errors

\* Generic greetings

\* Misspelled or unusual website domains

\* Requests for sensitive information



\### Social Engineering



The presentation explains how attackers can exploit human psychology through tactics such as:



\* Urgency

\* Authority

\* Fear

\* Curiosity

\* Pretexting



\### Protection Practices



Recommended practices include:



\* Verify the sender before trusting a message.

\* Check links before clicking.

\* Enable multi-factor authentication (MFA).

\* Use strong and unique passwords.

\* Never share sensitive information through suspicious messages.

\* Verify unusual requests through an independent communication channel.

\* Report suspicious emails to the appropriate security team.



\### Interactive Quiz



The presentation includes three awareness questions covering:



\* Urgent account-verification requests

\* Suspicious website domains

\* Social engineering involving gift-card requests



The answers and explanations are provided on the following slide.
